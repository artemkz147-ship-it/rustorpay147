# RuStore — Аниме на раздевание

Это отдельная ветка для приложения com.example.razdenjorickver2, Console App ID 2063635788 и товара bust1471. Основная ветка main и её файлы сохранены.

Импортировать RuStore_Anime_GDevelop.json в GDevelop. В комплектном проекте расширение уже встроено. Собрать Android штатной облачной сборкой GDevelop с прежними параметрами подписи и прежним аккаунтом. Плагин не генерирует ключи и не подписывает приложение: этим занимается GDevelop.

Нативный модуль получает SDK-подтверждённые покупки, сохраняет purchaseId перед ACKNOWLEDGED и выдаёт +100 один раз для каждой уникальной покупки. Незавершённые операции восстанавливаются. Предыдущие покупки из moon_save переносятся в новый реестр; перенести данные получится только при обновлении той же установки с совместимой подписью, без удаления приложения.

Бонус оценки одноразовый; SDK сообщает завершение сценария, а не факт отправленной оценки. Нет проверенного результата реальной тестовой оплаты или облачной сборки: после сборки требуется проверка на устройстве с подходящей подписью RuStore.
