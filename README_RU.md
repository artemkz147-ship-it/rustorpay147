# RuStore Pay для GDevelop

Нативный Cordova-плагин версии 1.0.3 для покупок RuStore Pay SDK 11.1.0 в Android-сборках GDevelop.

## Что делает

- инициализирует RuStore Pay по Console App ID;
- проверяет доступность покупок;
- получает товары;
- запускает покупку;
- получает список покупок и отдельную покупку;
- помечает выданную покупку как ACKNOWLEDGED;
- обрабатывает возврат в игру после окна оплаты через deeplink;
- не требует ручной правки проекта в Android Studio.

## Важно

Package Name Android-приложения и подпись приложения должны соответствовать приложению в консоли RuStore.
Console App ID — это числовой ID приложения в консоли RuStore, а не ID товара.

Этот репозиторий подключается к расширению GDevelop как Cordova dependency.

## Готовое расширение GDevelop

[Скачать RuStorePay_GDevelop_1.0.0.json](https://raw.githubusercontent.com/artemkz147-ship-it/rustorpay147/main/RuStorePay_GDevelop_1.0.0.json)

[Инструкция по импорту, покупке и подтверждению выдачи](GDEVELOP_RU.md).
Расширение настроено для Console App ID `2063744155` и закреплено на плагине 1.0.3.
JavaScript проверен тестами; импорт в GDevelop, Android-сборку и оплату нужно проверить отдельно.

## Обновление 1.0.3

- Pay SDK 11.1.0 подключается через BOM `2026.08.01`.
- Maven-репозиторий: `https://nexus-external.rustore.ru/repository/maven-rustore-exposed`.
- Console App ID и схема возврата передаются в AndroidManifest через строковые ресурсы.
- Console App ID по умолчанию: `2063744155`. Для другой игры его необходимо изменить при установке плагина через переменную `RUSTORE_CONSOLE_APP_ID`.

## Подключение обновления

Если зависимость в расширении GDevelop закреплена на старом коммите или теге,
обновите её ссылку на коммит с версией 1.0.3. Обновление репозитория само по себе
не меняет уже импортированное расширение или готовый APK.

Для ручной установки через Cordova:

```sh
cordova plugin add https://github.com/artemkz147-ship-it/rustorpay147.git --variable RUSTORE_CONSOLE_APP_ID=2063744155
```

Для обновления опубликованной игры сохраняйте прежний Package Name и настройки
подписи облачной сборки GDevelop; увеличьте номер версии игры.

После сборки проверьте на телефоне получение товаров, тестовую покупку,
возврат из банковского приложения и подтверждение выдачи товара.
При повторной обработке одной покупки товар не должен выдаваться повторно.
Изменения конфигурации не заменяют проверку реальной Android-сборки.
